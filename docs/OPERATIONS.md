# Operations and release privacy

Run task state and self-hosted workflows in your own private repository. Keep credentials and local machine settings outside Git. The distributed source uses disabled placeholders until initial configuration; no maintainer chats or active tasks are supplied.

`Start_CAH.bat` is an availability launcher, not workload acceptance. Successful execution requires the task's durable result and condition ledger. Network, GitHub Actions scheduling, browser hydration and model response time all remain part of delegation latency.

There is no universal emergency-stop button that terminates every already-running child process. Stop the runner to prevent new jobs; separately stop active executors or the bridge/browser automation as appropriate. Save work before terminating tools. The Task Cell does not replace operating-system process controls.

The public release contains sanitized reports and selected artifacts, not private raw logs. Identifiers, absolute machine paths, browser bindings, imported personal Skills and private repository history were excluded. PNG ancillary text metadata was removed while keeping compressed pixel data. The Blender asset was loaded with script auto-execution disabled, embedded text blocks removed, path fields cleared without resizing binary blocks, and loaded again for verification.

Do not publish the configured private instance by changing its visibility. Prepare a separate clean export instead. Open-source capability is retained: Skill Registry, continuity, dispatch, Worker lifecycle, host capabilities, executors and self-update are included.
