# Install CAH on Windows / Windows 安装入口

The supported v1.0.5 clean-source installation guide is [installation/README.md](../installation/README.md). The mandatory privacy re-deployment and re-planning instructions are [installation/UPGRADE_AND_REDEPLOY_V1_0_5.md](../installation/UPGRADE_AND_REDEPLOY_V1_0_5.md).

本发行包**不是可直接登录或运行的维护者实例**。必须在新的私有运行仓库中重新规划并配置用户自己的 GitHub 授权、Runner、Windows 路径、浏览器 Profile、ChatGPT Projects 及所需 GitHub Workflows；不得恢复发布前被脱敏的个人数据。

Start with the source privacy audit, plan the private environment, create a new private operational copy with installation/configure.py, and run Windows/Runner/Helper readiness checks before marking the installation usable. Do not execute Start_CAH.bat or Reset_CAH_Hot_State.bat against the unconfigured public source checkout.
