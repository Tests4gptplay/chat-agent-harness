# Shoe motion relative to the foot

Separate rigid shoe structure from soft straps and the foot. Identify Foot, Toe0 and calf influences using the actual skeleton.

Inspect rest and controlled walking/running poses. Compare the evaluated foot, shoe and strap geometry in one space, including heel clearance, toe pivot and strap slack.

Determine whether the requested effect is a rigid shoe rotating around the toe, a foot lifting from a loose shoe, or deforming footwear. Use the appropriate bone influences for each region rather than a single global weight blend.

Preserve insertion blocks and hard sole volumes. Blend flexible upper and strap weights smoothly. For a static misalignment, correct the local placement before changing animation weights.

Save a new copy and evaluate the same poses. Export with unchanged bone names and inspect the changed motion in the intended animation setup.
