Define the requested independent modules and stable material/section mapping. Bind controls to the owning SkeletalMeshComponent.

Store each click in the character's settings record. Reload the persisted state when the controller/widget is reconstructed. Reset only through the user's explicit Reset action.

Preserve the chosen menu layout and styling when repairing an input or ownership defect. Verify the actual FKey value and parsing path before redesigning the UI.
